HP LaserJet 1020 / 1020 Plus / 1018 driver

A native driver so these printers work from any app with Cmd-P on Apple Silicon and Intel Macs.

The installer will:

  • install the print filter and the USB backend,
  • download the printer's firmware from HP's Linux driver plug-in (OpenPrinting) and verify it. These printers need it uploaded after every power-on. Downloading it means you accept HP's plug-in license terms.
  • add the printer right away if it is plugged in. Otherwise, connect it later and choose it in System Settings → Printers & Scanners → Add Printer.

The first page after switching the printer on takes about 40 seconds longer while the firmware loads.
